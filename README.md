# Bitget Signal-Copy Bot

بوت تداول سبوت آلي لمنصة Bitget، بيعتمد بالكامل على توصيات قنوات تليجرام
المراقَبة (مفيش استراتيجية داخلية زي EMA/RSI). مبني بلغة Python، جاهز للنشر
على Railway.

> ⚠️ **البوت ده لتداول SPOT فقط.** مفيش رافعة مالية ومفيش بيع على المكشوف (short) —
> كل مركز بيتفتح هو شراء فعلي للعملة، وبيتقفل ببيعها تاني عند الستوب لوس أو
> هدف الربح المذكورين في التوصية.

## 💡 الفكرة الأساسية

1. البوت بيقرا رسايل من قناة/قنوات تليجرام إنت مشترك فيها كعضو عادي (عن طريق
   **Telethon** - حساب تليجرام شخصي، مش بوت).
2. لما توصية تجيلها الشكل المتوقع (اسم عملة + Enter + Stop + Target)، البوت
   يشتري Spot فوراً بمبلغ ثابت (قابل للتعديل)، ويراقب السعر لحد ما يوصل
   للستوب لوس أو هدف الربح، وبيقفل المركز (بيع) تلقائياً.
3. **Railway فيه بس أسرار الاتصال** (Bitget + تليجرام + قاعدة البيانات) -
   **كل حاجة تانية بتتحكم فيها لايف من تليجرام** بلوحة أزرار كاملة (`/menu`).

## ⭐ أوامر تليجرام

### معلومات
| الأمر | الوظيفة |
|---|---|
| `/status` | حالة البوت (شغال/متوقف، Dry Run/حقيقي، توصيات مفعّلة أو لأ) |
| `/settings` | كل الإعدادات الحالية بالتفصيل |
| `/balance` | الرصيد المتاح بالـ USDT |
| `/positions` | المراكز المفتوحة حالياً + الربح/الخسارة غير المحقق |
| `/trades` | آخر الصفقات المفتوحة المسجلة في قاعدة البيانات |
| `/pnl` | أداء اليوم (%) |
### قنوات التوصيات
| الأمر | الوظيفة |
|---|---|
| `/channelsignals` | آخر 10 توصيات اتقرأت من القنوات وحالتها (نُفذت/اتجاهلت وليه) |
| `/addchannel channel_username` | إضافة قناة للمراقبة لايف (من غير إعادة نشر) |
| `/removechannel channel_username` | حذف قناة من المراقبة |

أو من لوحة الأزرار: `/menu` → "📺 إدارة قنوات التوصيات"

### تشغيل / إيقاف
| الأمر | الوظيفة |
|---|---|
| `/pause` | إيقاف فتح صفقات جديدة (الحالية تفضل شغالة ومراقَبة) |
| `/resume` | استئناف فتح صفقات جديدة |
| `/dryrun_on` | تفعيل وضع التجربة فوراً بدون إيقاف السيرفر |
| `/dryrun_off` | تفعيل التداول الحقيقي فوراً |

### الإعدادات — كلها قابلة للتعديل لايف
| الإعداد | الوظيفة | افتراضي |
|---|---|---|
| `signal_trade_amount_usdt` | مبلغ ثابت (USDT) لكل توصية | 20 |
| `signal_price_tolerance_pct` | أقصى فرق مسموح بين السعر الحالي وسعر الدخول المذكور | 3% |
| `signal_trading_enabled` | تشغيل/إيقاف تنفيذ التوصيات (true/false) | true |
| `max_open_positions` | أقصى عدد مراكز مفتوحة في نفس الوقت | 2 |
| `max_daily_loss_pct` | إيقاف تلقائي لصفقات جديدة لو الخسارة اليومية وصلت للنسبة دي | 3% |
| `poll_interval_seconds` | كل قد إيه يتفحص المراكز المفتوحة (بالثانية) | 15 |

تغييرها: `/set <اسم_الإعداد> <القيمة>` — مثال: `/set signal_trade_amount_usdt 25`
أو من لوحة الأزرار: `/menu` → "🎛 ضبط الإعدادات العامة"

### طوارئ
| الأمر | الوظيفة |
|---|---|
| `/closeall confirm` | إغلاق كل المراكز فوراً بسعر السوق |

## 🛠 النشر على Railway

### أ) ارفع الكود على GitHub
ارفع محتويات الملف ده لريبو جديد على GitHub، وبعدين اربطه بمشروع على Railway
(New Project → Deploy from GitHub repo).

### ب) أضف قاعدة بيانات Postgres
في مشروعك على Railway: **+ New → Database → Add PostgreSQL**.
Railway هيحط متغير `DATABASE_URL` تلقائياً - متلمسهوش يدوي.

### ج) المتغيرات المطلوبة (Railway → Variables)

**أساسية (لازم البوت يشتغل من غيرها):**
| المتغير | من فين |
|---|---|
| `BITGET_API_KEY` | من إعدادات API في Bitget (صلاحية Spot Trade بس، من غير Withdraw) |
| `BITGET_API_SECRET` | من إعدادات API في Bitget |
| `BITGET_API_PASSPHRASE` | حددتها إنت وقت إنشاء الـ API key |
| `TELEGRAM_BOT_TOKEN` | من @BotFather |
| `TELEGRAM_CHAT_ID` | آيديك من @userinfobot |
| `DATABASE_URL` | **متضافش يدوي** — بتيجي تلقائي من Postgres plugin |

**اختيارية:**
| المتغير | الوظيفة |
|---|---|
| `TELEGRAM_ADMIN_IDS` | آيديات إضافية مصرح لها بالتحكم (بتتضاف لـ TELEGRAM_CHAT_ID) |
| `DRY_RUN` | `true` (افتراضي - آمن) أو `false` عشان يبدأ تداول حقيقي من أول تشغيل |

**لميزة قراءة قنوات التوصيات (لازمة عشان البوت يعمل حاجة أصلاً):**
| المتغير | من فين |
|---|---|
| `TELEGRAM_API_ID` | من [my.telegram.org](https://my.telegram.org) |
| `TELEGRAM_API_HASH` | من [my.telegram.org](https://my.telegram.org) |
| `TELEGRAM_SESSION_STRING` | بتتولد مرة واحدة محلياً - شوف تحت |
| `SIGNAL_CHANNELS` | يوزر أو آيدي القناة/القنوات، مفصولين بفاصلة |

**نصيحة أمان**: صلاحيات الـ API key في Bitget خليها Trade فقط، وامنع صلاحية السحب (Withdraw) نهائياً.

### د) التشغيل
Railway هيشغل `python -m bot.main` تلقائياً (حسب `Dockerfile`). لو لقيت خطأ
`can't open file 'main.py'` في اللوجز، يبقى فيه **Custom Start Command** متسجل
غلط في Settings → Deploy، امسحه خالص عشان يرجع يستخدم أمر Dockerfile الصحيح.

راقب اللوجات من **Deployments → Logs**، وبمجرد ما يشتغل هيبعتلك رسالة ترحيب على تليجرام.

## 2. توليد TELEGRAM_SESSION_STRING (مرة واحدة بس - على جهازك)

الميزة دي أساسية للبوت (هي مصدر التوصيات الوحيد)، فمن غيرها البوت هيفضل شغال
بس مش هيعمل حاجة.

1. روح [my.telegram.org](https://my.telegram.org) وسجل دخول برقمك، وخد `API_ID` و `API_HASH`
   من "API development tools".
2. على جهازك الشخصي (مش على Railway):
   ```bash
   pip install telethon
   python generate_session.py
   ```
   هيطلب منك API_ID و API_HASH ورقم تليفونك وكود التفعيل، وفي الآخر هيطبعلك
   **Session String** طويل — ده بمثابة تسجيل دخول دائم لحسابك، احتفظ بيه سري
   ومتشاركوش مع حد.
3. حط الناتج في Railway → Variables → `TELEGRAM_SESSION_STRING`، وضيف كمان
   `TELEGRAM_API_ID` و`TELEGRAM_API_HASH` و`SIGNAL_CHANNELS`.
4. اضبط المبلغ الثابت لكل توصية: `/set signal_trade_amount_usdt 20`
5. البوت هيبدأ يقرأ الرسايل الجديدة (اللي بعد التشغيل بس - مش القديمة).
   شوف `/channelsignals` في أي وقت عشان تعرف إيه اللي اتنفذ وإيه اللي اتجاهل وليه.

**شكل الرسالة اللي البوت بيفهمها:**
```
اسم_العملة 🔥
Long 15x
Enter : 0.041
Target : 0.0505
Stop : 0.0398
```

**تقسيم الأهداف والستوب المتحرك (Trailing Stop):**
كل توصية بتتقسم دايماً لـ **3 أهداف بالظبط**، بغض النظر عن عدد الأهداف
المذكورة فعلياً في الرسالة:
- **هدف واحد بس مذكور**: بيتقسم لـ 3 مراحل متساوية المسافة بين سعر الدخول
  والهدف (الهدف النهائي بيفضل زي ما هو بالظبط).
- **هدفين مذكورين**: بياخدهم زي ما هما، وبيضيف هدف تالت بمد نفس المسافة.
- **3 أهداف أو أكتر**: بياخد أقرب 3 أهداف (الأسهل تحقق).

الكمية بتتقسم 3 أجزاء متساوية، كل جزء مرتبط بهدف مختلف. وبعد كل هدف يتحقق،
الستوب لوس للأجزاء الباقية بيترفع تلقائياً:
- بعد الهدف الأول → الستوب بيترفع لسعر الدخول (تعادل - مفيش خسارة ممكنة بعد كده).
- بعد الهدف الثاني → الستوب بيترفع لسعر الهدف الأول (تأمين ربح إضافي).
- وهكذا لكل هدف بعده.

توصيات **Short** بيتم تجاهلها تلقائياً لأن البوت سبوت فقط. رقم الرافعة (15x)
بيتقرا بس **مش بيتطبق** - التنفيذ دايماً بدون رافعة.

## 3. التشغيل محلياً (اختياري للتجربة)

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # واملأ القيم
export $(cat .env | xargs)
python -m bot.main
```

## تنبيهات مهمة

- هذا الكود أداة تقنية فقط، مش نصيحة استثمارية. حتى تداول السبوت (من غير رافعة) فيه مخاطرة ويمكن يؤدي لخسارة جزء أو كل رأس المال المخصص للتداول.
- جرّب `/dryrun_on` كام يوم من تليجرام قبل ما تحول لتداول حقيقي بـ `/dryrun_off`، عشان تتأكد إن القراءة والتنفيذ شغالين صح.
- تأكد من صلاحيات الـ API محدودة بالتداول فقط بدون سحب.
- قنوات التوصيات كتير منها غير موثوق (بامب وضخ). التنفيذ التلقائي بياخد التوصية زي ما هي بدون أي تحليل أو تقييم لجودتها - المسؤولية عليك بالكامل في اختيار القناة والمبلغ المناسب لكل توصية.
