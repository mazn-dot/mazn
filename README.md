# BNB Wallet Tracker Bot

بوت Telegram لمراقبة تحويلات BEP-20 على BNB Smart Chain + اكتشاف وتتبع الحيتان.

## متغيرات Railway المطلوبة

يحتاج البوت فقط إلى المتغيرين الضروريين لتشغيل Telegram والتحكم بالوصول:

- `TELEGRAM_BOT_TOKEN`: توكن البوت من BotFather.
- `TELEGRAM_CHAT_ID`: رقم المحادثة المالكة للبوت.

يجلب البوت سجلات `Transfer` من **BNB Smart Chain Public RPC** بلا مفتاح، ويجلب السعر والرمز من **Dexscreener Public API** بلا مفتاح.

## الميزات الجديدة (v2)

### 1. إصلاح عرض العملات
- فك ترميز محسّن لـ `symbol()` و `name()` (يدعم string و bytes32).
- fallback تلقائي إلى Dexscreener عند فشل الـ RPC → يقل ظهور `???`.

### 2. Score يعتمد على الكمية + عدد التحويلات
- الترتيب لم يعد يعتمد على الكمية فقط.
- الصيغة: `score = amount × (1 + count^0.6 / 8)`
- يظهر مؤشر 🔥 أو ⚡ عند نشاط تحويلات عالي → يساعد على اقتناص الضغط المنسق.

### 3. بحث وتتبع الحيتان
- زر **🐋 حيتان توكن**: أرسل عنوان أي توكن → يعرض أكبر المحافظ النشطة عليه.
- إضافة حوت بسهولة: `إضافة حوت اسم 0x...`
- إضافة/حذف محافظ من داخل التليجرام.

## التشغيل

```bash
python bot.py
```

## الأوامر السريعة داخل البوت

| الأمر | الوظيفة |
|-------|---------|
| `إضافة اسم 0x...` | إضافة محفظة للتتبع |
| `إضافة حوت اسم 0x...` | إضافة محفظة حوت |
| `حذف الاسم` | حذف محفظة |
| زر 🐋 حيتان توكن | بحث عن حيتان توكن معين |

## الوظائف الأساسية

- 📥 الدخول / 📤 الخروج
- 🎯 الفرصة / 🚫 النقية
- 🏆 الأفضل (عبر نوافذ زمنية متعددة)
- 🔭 اكتشاف المحافظ المتفاعلة
- 🐋 بحث حيتان توكن

## تنبيه عن المصدر المجاني

المصادر العامة مجانية حالياً لكنها ليست مضمونة إلى الأبد، وقد تفرض حدوداً أو تتوقف مؤقتاً. الكود يحتوي على تخزين مؤقت وحد محلي للطلبات. بيانات الأسعار والتوكنات للعرض والمراقبة وليست ضماناً لتنفيذ تداول.
