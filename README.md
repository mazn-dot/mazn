# BNB Wallet Tracker Bot

بوت Telegram لمراقبة تحويلات BEP-20 على BNB Smart Chain.

## متغيرات Railway المطلوبة

يحتاج البوت فقط إلى المتغيرين الضروريين لتشغيل Telegram والتحكم بالوصول:

- `TELEGRAM_BOT_TOKEN`: توكن البوت من BotFather.
- `TELEGRAM_CHAT_ID`: رقم المحادثة المالكة للبوت.

تمت إزالة `MORALIS_API_KEY` بالكامل. يجلب البوت سجلات `Transfer` من **BNB Smart Chain Public RPC** بلا مفتاح، ويجلب السعر العام من **Dexscreener Public API** بلا مفتاح. لا توجد أسرار جديدة ولا متغيرات خاصة بجلب البيانات.

## تنبيه عن المصدر المجاني

المصادر العامة مجانية حاليًا لكنها ليست مضمونة إلى الأبد، وقد تفرض حدودًا أو تتوقف مؤقتًا. أضاف الكود تخزينًا مؤقتًا وحدًا محليًا للطلبات لتخفيف الضغط. قراءة 24 ساعة قد تحتاج عدة دفعات من سجلات RPC، لذلك قد تكون أبطأ أو تُرجع نتائج فارغة عندما يحد المصدر العام الطلبات. بيانات الأسعار والتوكنات للعرض والمراقبة وليست ضمانًا لتنفيذ تداول.

## التشغيل

```bash
python bot.py
```

## الوظائف

تظل أزرار الدخول والخروج والفرصة والنقية والأفضل والاكتشاف والمحافظ كما هي. يتم اكتشاف التحويلات من سجلات ERC-20 القياسية، مع روابط Dexscreener وBscScan التي ينتجها `formatter.py`.
